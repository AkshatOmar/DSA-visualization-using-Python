# DSA-visualization-using-Python

This repository contains three Python programs that:

1. Visualize a hash table in 2D and 3D.
2. Visualize Dijkstra’s Algorithm in 2D and 3D with animation.
3. Visualize a complete binary tree.
Each program takes user input, processes it, and visualizes it using the matplotlib library.
